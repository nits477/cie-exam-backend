CIE WEBSITE / BACKEND V3.9.8
================================

This package contains only the website and backend.
The Android app is NOT included and has NOT been changed.

GITHUB UPDATE
1. Open your cie-exam-backend GitHub repository.
2. Upload all files and folders from this package to the repository root.
3. Allow GitHub to replace files with the same names.
4. Commit the changes.
5. Render will deploy automatically if Auto-Deploy is enabled.
   Otherwise, open Render > Deploys > Deploy latest commit.

IMPORTANT
- Keep existing Render environment variables unchanged.
- Do not upload this package into the Android Studio app project.
- package.json version: 3.9.8
